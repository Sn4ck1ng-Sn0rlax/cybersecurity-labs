# CTF & Wargame Writeups

Writeups from capture-the-flag exercises and wargames, organized by platform. Each writeup is written as a formal incident/investigation report rather than a casual step-by-step walkthrough, to practice communicating technical findings the way a real SOC report requires.

## Platforms

| Folder | What it covers | Status |
|---|---|---|
| `htb-junior-cybersecurity-analyst/` | Hack The Box's Junior Cybersecurity Analyst path — SOC-oriented, blue-team focused modules. | In progress |
| `overthewire-bandit/` | OverTheWire's Bandit wargame — Linux fundamentals, command-line proficiency, and privilege escalation basics. Written up more informally than the analyst-path reports, since the skill being demonstrated (Linux fluency) is different from alert-driven analysis. | Planned |
| `tryhackme/` | Individual TryHackMe rooms, including the SOC Level 1 path. | Planned |

## Note on format

Not every writeup here follows the same template. HTB analyst-path exercises and TryHackMe SOC rooms are documented as formal incident reports, since that mirrors real SOC communication. Bandit levels are documented more simply, as a running log of commands, techniques learned, and what tripped me up, since a wargame focused on Linux fundamentals doesn't map naturally onto an incident-report format.
